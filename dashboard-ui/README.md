# Food Khata Dashboard Frontend

The frontend is a React + Vite single-page application styled with Tailwind CSS and official shadcn/ui components (Radix primitives). It connects to the local `food_khata.serve` FastAPI service over loopback and provides five interactive analytics views with account-scoped and URL-synchronized filters, built on a shared BaseChart component, semantic design tokens, and 5 accent themes (light/dark).

## Views

- **Overview (`/`)**: High-level spending summary, delivered KPIs, spend waterfall, top restaurants and dishes, loyalty rankings, and ordering habit highlights.
- **Spending (`/spending`)**: Cumulative daily spend, rolling 30-day pace, annual comparisons, fee breakdown scatter, and discount distributions.
- **Food (`/food`)**: Diet classification split (Veg / Non-Veg / Unknown), cuisine rankings, restaurant repeat rates, and item price history.
- **Habits (`/habits`)**: Weekday x hour ordering heatmap, meal slot analysis, order size histograms, and ordering streaks / gaps.
- **Orders (`/orders`)**: Complete order history table with server-side sorting and pagination, search, filter presets, CSV export, and accessible centered order receipt modal.
- **Legacy (`/legacy`)**: Fallback single-page dashboard for offline static JSON exports generated by `food-khata export`.

## Development

Run the backend API and frontend dev server in separate terminals:

1. **Start the API service** (from repo root):
   ```powershell
   python -m food_khata serve --dev
   ```
   The backend runs on `http://127.0.0.1:8765`.

2. **Start the Vite dev server** (inside `dashboard-ui/`):
   ```powershell
   npm ci
   npm run dev
   ```
   Vite proxies all `/api` requests to `127.0.0.1:8765`.

## Design system

All design tokens live in `src/style.css` as CSS variables; nothing else may hold a colour literal (`npm run lint` enforces it).

- **Surfaces and text**: `--background`, `--surface`, `--surface-2`, `--border`, `--foreground`, `--muted-foreground`.
- **Accent** (`emerald`, `indigo`, `amber`, `rose`, `slate`, each in light and dark): `--primary`, `--primary-foreground`, `--accent`, `--chart-1..8`.
- **Semantic colours, independent of the accent**: `--success`, `--warning`, `--danger`, `--info`. Notices use a neutral tinted surface (`.notice`) with a coloured icon only.
- **Platform colours**: `--platform-zomato`, `--platform-swiggy`, used by charts, pills and tables.
- **Focus**: `--focus` (not tied to the accent, so Slate stays visible).
- **Type scale**: `--fs-caption` 12px, `--fs-body` 14px, `--fs-lead` 16px, `--fs-title` 20px, `--fs-heading` 24px, `--fs-display` fluid (Total spend only). Sentence case everywhere.
- **Spacing, radius, shadow, motion**: `--space-card`, `--space-gap`, `--radius*`, `--shadow-*`, `--motion-*` (all motion honours `prefers-reduced-motion`).
- Charts read these tokens at draw time (`getCurrentChartTheme`), and the page remounts its charts on a mode, accent or pattern change, so nothing lags. "Accessible patterns" (hatch fills) is opt-in in the Appearance menu.
- Shared primitives: `PageHeader`, `Card`, `Money`, `StatusPill`/`PlatformPill`, `ChartCard` (alias `ChartFrame`), `PageLoading`/`PageError`/`PageEmpty`. Navigation items come from one array, `src/app/nav.ts`.
- `npm run lint` also runs `scripts/contrast-check.mjs`: text levels and semantic colours on every surface, all 10 light/dark x accent combinations.

## Verification & Testing

Run these commands from `dashboard-ui/`:

- **Unit tests**: `npm test` (runs Node assert suites and Vitest component/lib tests)
- **Type checking**: `npm run typecheck` (`tsc --noEmit`)
- **Linting**: `npm run lint` (`eslint .`)
- **Production build**: `npm run build` (outputs optimized bundle to `dist/`)
- **Browser tests**: `npm run test:browser` (Playwright Chromium interaction suite)
- **Synthetic foundation suite**: `node scripts/foundation-test.mjs`

## Privacy & Safety

Do not publish private exports in `public/data/` or builds containing personal data. All `.food-khata/` directories, `*.db`, `public/data/`, and exports are strictly gitignored.
