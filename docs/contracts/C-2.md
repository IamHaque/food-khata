# Contract C-2 (production plan)

`openapi.json` is the frozen C-1 contract from the access plan. `openapi-c2.json` is the current API (regenerated with `python scripts/export_openapi.py`, then `npm --prefix dashboard-ui run generate:api` for the UI types).

Additive (old clients keep working):

- `GET /api/accounts` returns one row per (account, provider); `provider` is optional on sync create, verify-again and disconnect (422 `PROVIDER_REQUIRED` when the account has several).
- `GET /api/accounts/providers`; `added_to_existing` on link verify.
- `POST /api/dashboard` accepts `sections`; `/api/orders/slim` is capped at 5,000 rows with `truncated`.
- Sync jobs: `queue_position`, `eta_seconds`, `import_pending`; `POST /api/sync/jobs/{id}/retry-import`; 409 `ACCOUNT_BUSY`.
- Auth and owner: `POST /api/auth/password`, `POST /api/auth/logout-all`, `POST /api/owner/users/{id}/remove`, `GET /api/owner/audit`, `GET /health/ready`; data health returns `quarantined_orders`.

Breaking (DEV-13, DEC-P3): `POST /api/sync/jobs/{id}/code` is removed. A code cannot repair an expired provider session; the client sends the user to Verify again, which resumes the job.

Behaviour changes: `POST /api/auth/register` never creates the owner (only `/api/owner/setup` does); the `x-session-id` header is no longer a session; sessions end after 8 hours idle or 7 days; a request body over 64 KB gets 413 and one without a length gets 411.
